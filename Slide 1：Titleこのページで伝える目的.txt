MPCが各時間ステップで「予測・最適化・制御」を繰り返して制御入力を決める仕組みを説明する。   英語原稿
Let me briefly explain MPC. MPC repeats three steps at each time step. First, prediction: it predicts future system behavior using a system model. Second, optimization: it calculates optimal control inputs from the prediction. Third, control: it applies the first control input to the system. Repeating this loop lets MPC control the system step by step.日本語訳
MPCについて簡単に説明します。MPCは各時間ステップで3つのステップを繰り返します。1つ目は予測で、システムモデルを使って将来のシステムの動きを予測します。2つ目は最適化で、予測をもとに最適な制御入力を計算します。3つ目は制御で、最初の制御入力をシステムに適用します。このループを繰り返すことで、MPCは段階的にシステムを制御します。前後のページとのつながり
モデルに基づくMPCの仕組みを説明したあと、次の Slide 6 で「そこに強化学習を組み合わせるRRL」の仕組みへつなげる。   Slide 6：Residual Reinforcement Learningこのページで伝える目的
既存制御器とRLポリシーを並列に足し合わせるRRLの仕組みと利点を、聞き手が理解できるように説明する。   英語原稿
Next, let me explain RRL. RRL combines an existing controller with a reinforcement learning policy. The existing controller generates the base control input. The RL policy learns an additional control input, called the residual input. These two inputs are added together to make the final control input. The benefit of RRL is that it uses an existing controller and learns only extra compensation for errors.日本語訳
次に、RRLについて説明します。RRLは既存の制御器と強化学習ポリシーを組み合わせる手法です。既存の制御器が基本となる制御入力を生成します。RLポリシーは、残差入力と呼ばれる追加の制御入力を学習します。これら2つの入力を足し合わせて、最終的な制御入力を作ります。RRLの利点は、既存の制御器を活用しながら、誤差を補う追加分だけを学習できることです。前後のページとのつながり

Here is the reward function used to train RRL. The first three terms penalize tracking errors in joint angle, angular velocity, and angular acceleration. The remaining terms manage the learning behavior. Specifically, r ratio checks the size of the residual torque. r conflict gives a penalty when MPC and RRL push in opposite directions. r penalty penalizes large tracking errors.日本語訳
こちらはRRLを学習させるための報酬関数です。最初の3つの項は、関節角度、角速度、角加速度の追従誤差にペナルティを与えます。残りの項は学習の挙動を調整します。具体的には、r ratioは残差トルクの割合を見ます。r conflictはMPCとRRLが反対方向の力を出すときにペナルティを与えます。r penaltyは大きな追従誤差に対するペナルティです。前後のページとのつながり
